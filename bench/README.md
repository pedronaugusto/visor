# visor's benchmarks

The shared measurement migration is work in progress. A default full pass
stops at `style_heavy`: its draw-only timing boundary requires untimed
restyling between frames, which the published callback API cannot express.
Check and smoke invocations retain that workload's behavior without timing it.

```sh
zig build bench-build
zig-out/bench/visor-bench --smoke
zig-out/bench/visor-bench --row cell_reads/
```

`preflight.Config.bench` compiles the drivers in ReleaseFast and provides
`bench`, `bench-build` and `bench-ab`, including shakedown's comparison tool.
`zig build test` runs the independent workload checks and one smoke frame
for each of 63 workloads at 8x4. Full passes check at 8x4, 80x24, 120x40 and
200x60, then measure the three larger grids. Inputs are generated by
`corpus.zig` into `corpus/` beneath the temporary working directory.

Rows are named `<workload>/<cols>x<rows>`, with unit `frame`. Driver setup,
corpus reads and output capacity reservation precede the measured callback.
`shakedown.bench` owns warmup, adaptive batching, sample statistics, provenance
and JSONL output. Full rows retain seven samples and begin with 1,000 frames, or 100 for
`canvas_raster` and `picture_frame_sixel`; the shared module calibrates from
there. Smoke rows have no clock readings or timing statistics. Visor owns no
measurement loop or comparison implementation. `--row PREFIX` selects rows;
unknown prefixes fail. The former `--runs` and `--only` options are removed.

Each workload retains its own process so its fixtures and widget state do
not cross into another workload. Process startup, checks and reporting are
outside the measured callback. Direct invocations remain:

- `visor-bench draw <task> <check|smoke|full> <cols> <rows> <iterations>`
- `visor-bench ops <task> <check|smoke|full> <cols> <rows> <iterations>`
- `visor-bench ops list-tasks`

Operations read the directory named by `VISOR_BENCH_CORPUS`. Check invocations
print their evidence followed by `result\t<frames>\t<count>\t<bytes>\t0`.
Smoke and full invocations emit shared JSONL instead of the former timing
protocol. The initial batch argument applies to full measurement; shared
smoke runs one frame. Checks retain the requested frame count.

The eight drawing-core names and 55 operation names remain in `workloads.zig`.
`terminal.zig` independently decodes drawing frames and verifies their cells,
styles, links and placements using a second uucode table. `ops_check.zig`
checks operation evidence. `pictures.zig` decodes sixel and PNG data to verify
picture behavior. These are workload compatibility checks, not measurement
implementations.
